# Workshops

Материалы для воркшопов (практических занятий) от Inview.

## Структура репозитория

- `01-opensearch-workshop/` — воркшоп по OpenSearch: конфигурация кластера через Docker Compose, настройка безопасности (securityadmin) и дашборды OpenSearch
- `02-whitespots/` — воркшоп по WhiteSpots и технологиям DevSecOps: установка Auditor и AppSec Portal, добавление репозиториев и сканирование на уязвимости
- `2026/01-intro/` — вводный воркшоп: метрики и алертинг (подготовка, пошаговые инструкции, готовые конфиги)
- `2026/02-git/` — шпаргалка по Git: основные команды, ветки, теги, слияния
- `2026/04-ci-cd/` — воркшоп по CI/CD на GitLab: базовая часть (настройка GitLab Runner, базовый pipeline, проверка качества кода, артефакты и деплой на простом приложении на Go) и продвинутая (настройка runner с Docker-executor, исправление pipeline, автоматизация релиза приложения)
