# Руководство по подготовке

Если Вы являетесь уверенным пользователем Linux/MacOS, у Вас установлен Docker и Вы умеете его использовать - можно пропустить часть этого руководства и выполнить только пункт [Загрузка образов](#загрузка-образов).

Для пользователей Windows мы **настоятельно** рекомендуем установить виртуальную машину (далее по тексту - ВМ, VM) с последней версией ОС Ubuntu x64 (в данный момент 26.04.1 LTS).


## Что делать, если я не знаю, с чего начать?

Для начала гайд по установке VirtualBox и установке Ubuntu в ВМ: https://ru.hexlet.io/blog/posts/virtualbox

В статье есть ссылка на образ Ubuntu - на странице загрузки необходимо выбрать образ Ubuntu 26.04.1 LTS для "Intel or AMD 64-bit architecture" и скачать его (вес образа ~6 ГБ).

Мы рекомендуем следующие параметры для ВМ:
- 2 ядра
- 6 (или 8) ГБ RAM
- Виртуальный жёсткий диск: 30-40 ГБ

Далее установка ОС производится по шагам в статье. Альтернативно можно ознакомиться с официальным [гайдом](https://ubuntu.com/desktop/docs/en/latest/tutorial/install-ubuntu-desktop/#follow-the-installer) по установке (там более актуальные скриншоты для текущей версии, но суть не меняется).

## Установка Docker

После успешной загрузки в Ubuntu Вам необходимо установить Docker - здесь рекомендуем воспользоваться [официальной документацией](https://docs.docker.com/engine/install/ubuntu/) для Ubuntu.

После установки Docker и при попытке его использования Вы можете столкнуться с отсутствием прав. В таком случае необходимо либо выполнить команду от пользователя root (через sudo), либо добавить своего пользователя в группу, выполнив в терминале команду `sudo usermod -aG docker $USER` (затем перезапустить терминал).

Не забудьте также выполнить `systemctl start docker` и `systemctl enable docker`.

В случае, если после выполнения команды `docker run hello-world`, вы видите следующее сообщение - Вы великолепны и готовы к воркшопу!

```
Hello from Docker!
This message shows that your installation appears to be working correctly.

<ещё много текста>
```

## Загрузка образов

!!!Также мы очень просим Вас выполнить заранее загрузку необходимых Docker-образов, чтобы не тратить на это время на самом воркшопе (предполагается, что Вы уже склонировали или скачали и распаковали репозиторий):

```
cd work
docker compose pull
```

## Подготовка почтового аккаунта

В рамках воркшопа мы настроим уведомления о событиях мониторинга на почту, поэтому необходимо заранее подготовить свой почтовый аккаунт. Нам потребуются сведения об аккаунте (скорее всего потребуется сгенерировать пароль приложения) и адрес/порт SMTP сервера почтового провайдера (гайд для [Яндекс-почты](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others), [Gmail](https://support.google.com/mail/answer/7104828?hl=ru)).

Указанные данные можно сразу вписать в `work/alert_manager/config.yaml`.

Вот пример для Яндекс-почты (где `your-password` - это пароль приложения - подробнее в гайде выше):
```
global:
  smtp_smarthost: 'smtp.yandex.ru:465'
  smtp_from: 'your-email-address@yandex.ru'
  smtp_auth_username: 'your-email-address@yandex.ru'
  smtp_auth_password: 'your_password'
  smtp_require_tls: false
...
<много текста>
```
